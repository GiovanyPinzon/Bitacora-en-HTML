REGLAS DE POLITICA

    Reglas de Registro

    1. Responsabilidad Única (SRP)

    Cada fila debe documentar un solo evento, tarea o impedimento indivisible. Si se realizaron tres actividades durante el día, se deben registrar en tres filas independientes.

    2. Cero Adjetivos Subjetivos

    Está prohibido utilizar expresiones subjetivas como:

    • “Estuvo chévere”.
    • “Fue difícil”.
    • “Avanzamos bien”.

    Los registros deben contener únicamente hechos técnicos verificables.

    3. Inmutabilidad

    Los registros históricos no deben eliminarse ni sobrescribirse. Si un registro contiene un error o requiere un cambio, se debe crear un nuevo registro con la fecha actual e indicar:

    “Corrección/Ajuste al registro ID [X]”

    4. Impedimentos

    Si no se presentaron dificultades durante la ejecución de una actividad, se debe escribir expresamente:

    “Sin impedimentos operativos”.

    Si se presentó un impedimento, se debe describir técnicamente qué se ejecutó, qué falló y qué resultado se esperaba.

    Guía de Llenado

    ID

    Número consecutivo y único para cada actividad o fila. Ejemplo: 001, 002, 003.

    Timestamp (YYYY-MM-DD HH:MM)

    Fecha y hora exacta en la que se registra o ejecuta la actividad, utilizando el formato AAAA-MM-DD HH:MM.

    Autoría (Responsable)

    Nombre o iniciales del aprendiz responsable de ejecutar la actividad.

    Objeto Técnico (Actividad y Alcance)

    Descripción técnica, objetiva, concreta y verificable de la actividad realizada y su alcance real.

    Evidencia de Ejecución (Entregable / Enlace)

    URL del commit, enlace al Pull Request, captura de pantalla o documento entregable que permita verificar la ejecución de la actividad.

    Impedimentos / Blockers

    Descripción técnica del error o impedimento presentado, indicando qué se ejecutó, qué falló y qué resultado se esperaba. Si no hubo dificultades, escribir:

    “Sin impedimentos operativos”.

    Plan de Acción (Mitigación / Próxima Tarea)

    Acción correctiva realizada, próxima tarea programada o paso necesario para continuar con la actividad o solucionar el impedimento.

    Principio General

    • Único: cada registro corresponde a una actividad.
    • Verificable: debe contar con evidencia.
    • Objetivo: debe contener hechos técnicos.
    • Trazable: debe permitir identificar responsable y evidencia.
    • Inmutable: los registros históricos no se sobrescriben.
